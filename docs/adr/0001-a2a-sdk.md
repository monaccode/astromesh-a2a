# ADR 0001 — The `a2a-sdk` 1.x surface we build on

- **Status:** Accepted
- **Date:** 2026-10-19
- **SDK version read:** `a2a-sdk` 1.2.3 (protocol `1.0`), pinned `>=1.2,<2`
- **Evidence:** every signature below was read from the installed package source, and the
  client/server snippets were executed end to end against an in-process uvicorn server
  (see [Verified run](#7-verified-run)).

## Context

`astromesh-a2a` is a safety, policy and adapter layer on top of the official A2A Python SDK.
The protocol (wire format, JSON-RPC methods, SSE, task lifecycle) belongs to the SDK; we own
egress safety, remote-agent policy, turn origin, budgets, trace and framework adapters. Later
tasks (`net`, `policy`, `client.RemoteAgent`, `server.create_app/serve`, adapters) are written
against this document, so it fixes the exact SDK pieces we import and the gaps we fill.

## Decision

Build on the SDK's **JSON-RPC binding only** (`TransportProtocol.JSONRPC`), with:

- **Client:** `ClientFactory(ClientConfig(httpx_client=<our safe client>))` →
  `create_from_url(...)` / `create(card)` → `BaseClient`. Our `httpx.AsyncClient` carries the
  pinned, size-capped transport from `net`. Auth, `traceparent` and per-call timeout go through a
  `ClientCallInterceptor` that writes `ClientCallContext.service_parameters` (HTTP headers).
- **Server:** our `AgentExecutor` subclass + `DefaultRequestHandler` + `InMemoryTaskStore`,
  mounted as plain Starlette routes from `create_agent_card_routes` and `create_jsonrpc_routes`;
  authentication via Starlette `AuthenticationMiddleware` (the SDK has none of its own).
- **Models:** the SDK's protobuf messages (`a2a.types`), serialized with
  `google.protobuf.json_format`. We never expose protobuf types in our public API; `Result`,
  `CardSpec`, `Skill` are our own dataclasses converted at the edge.

gRPC and HTTP+JSON (REST) bindings and the v0.3 compat layer are out of scope for 0.1.0.

## 1. Client

### 1.1 Building a client

```python
# a2a/client/client.py
@dataclasses.dataclass
class ClientConfig:
    streaming: bool = True                       # use SendStreamingMessage when card allows
    polling: bool = False                        # sets configuration.return_immediately
    httpx_client: httpx.AsyncClient | None = None
    grpc_channel_factory: Callable[[str], Channel] | None = None
    supported_protocol_bindings: list[str] = []  # empty => JSONRPC only
    use_client_preference: bool = False
    accepted_output_modes: list[str] = []
    push_notification_config: TaskPushNotificationConfig | None = None

class ClientCallContext(pydantic.BaseModel):
    state: MutableMapping[str, Any] = {}
    timeout: float | None = None                 # -> httpx.Timeout(timeout) per request
    service_parameters: dict[str, str] | None = None   # -> extra HTTP headers

# a2a/client/client_factory.py
class ClientFactory:
    def __init__(self, config: ClientConfig | None = None): ...
    async def create_from_url(self, url: str,
        interceptors: list[ClientCallInterceptor] | None = None,
        relative_card_path: str | None = None,
        resolver_http_kwargs: dict[str, Any] | None = None,
        signature_verifier: Callable[[AgentCard], None] | None = None) -> Client: ...
    def create(self, card: AgentCard,
        interceptors: list[ClientCallInterceptor] | None = None) -> Client: ...

async def create_client(agent: str | AgentCard, client_config=None, interceptors=None,
    relative_card_path=None, resolver_http_kwargs=None, signature_verifier=None) -> Client

# a2a/client/card_resolver.py
class A2ACardResolver:
    def __init__(self, httpx_client: httpx.AsyncClient, base_url: str,
                 agent_card_path: str = '/.well-known/agent-card.json'): ...
    async def get_agent_card(self, relative_card_path: str | None = None,
        http_kwargs: dict[str, Any] | None = None,
        signature_verifier: Callable[[AgentCard], None] | None = None) -> AgentCard: ...
def parse_agent_card(agent_card_data: dict[str, Any]) -> AgentCard   # handles v0.3 card shapes
```

Public imports: `from a2a.client import ClientFactory, ClientConfig, ClientCallContext,
A2ACardResolver, ClientCallInterceptor, A2AClientError, A2AClientTimeoutError,
AgentCardResolutionError, create_client`.

**How we will use it (T5):** fetch the card ourselves through `net` (so policy runs before any
SDK object exists), parse with `a2a.client.card_resolver.parse_agent_card`, apply policy
(host, version, signature), then `ClientFactory(config).create(card, interceptors)`. This keeps
the SDK from fetching anything we have not vetted. `create_from_url` is equivalent when the
card fetch can go through the same safe client.

Behaviour that matters:

- `ClientFactory.__init__` **mutates our client**: `httpx_client.headers.setdefault('A2A-Version',
  '1.0')`. That is how the version header is set on every request (card GET included — measured).
- `create()` picks the interface: among `card.supported_interfaces` with `protocol_binding ==
  'JSONRPC'` it prefers `protocol_version` major.minor `== 1.0`, then `> 1.0`, then `>= 0.3`, then
  unversioned. A `0.3` interface silently gets `CompatJsonRpcTransport`. **The client never
  rejects a version**: `UnsupportedVersion` is our check (§6).
- No compatible interface → plain `ValueError('no compatible transports found.')`.
- If the selected interface has a `tenant`, the transport is wrapped in `TenantTransportDecorator`.
- **`client.close()` closes the httpx client we passed in** (`JsonRpcTransport.close` →
  `httpx_client.aclose()`; measured `is_closed == True`). `RemoteAgent` must own the httpx client
  and either build one per SDK client or never call `client.close()` while it reuses the pool.
- The card resolver calls `response.raise_for_status()`; httpx raises on 3xx too, and
  `httpx.AsyncClient` does not follow redirects by default, so a redirecting card host fails as
  `AgentCardResolutionError` (we still set `follow_redirects=False` explicitly in `net`).

### 1.2 Passing our own transport (IP pinning + size cap)

The SDK only touches the network through the `httpx.AsyncClient` it receives: `JsonRpcTransport`
calls `httpx_client.build_request(...)` + `httpx_client.send(request)` (blocking) or
`send(request, stream=True)` + `response.aiter_lines()` (SSE); the card resolver calls
`httpx_client.get(...)`. So the hook is:

```python
hx = httpx.AsyncClient(
    transport=PinnedTransport(policy), follow_redirects=False, timeout=httpx.Timeout(policy.timeout)
)
factory = ClientFactory(ClientConfig(httpx_client=hx, streaming=True))
```

`PinnedTransport(httpx.AsyncBaseTransport).handle_async_request` (T2) resolves and checks the
host, pins the IP, and wraps the response stream in a byte counter that raises once
`max_bytes` is exceeded. Measured: the SDK sent both the card GET and every JSON-RPC POST
(blocking and SSE) through a custom `AsyncBaseTransport`.

Note the SDK reads bodies with `response.json()` (blocking) and `aiter_lines()` (SSE) with no
size limit of its own — the cap **must** live in the transport's response stream. For SSE the
cap should be per event *and* per stream (a stream that never ends is also handled by our
wall-clock/event caps, §6).

### 1.3 Sending: blocking vs streaming

```python
# a2a/client/client.py (abstract), implemented by a2a/client/base_client.py:BaseClient
async def send_message(self, request: SendMessageRequest, *,
                       context: ClientCallContext | None = None) -> AsyncIterator[StreamResponse]
async def get_task(self, request: GetTaskRequest, *, context=None) -> Task
async def cancel_task(self, request: CancelTaskRequest, *, context=None) -> Task
async def subscribe(self, request: SubscribeToTaskRequest, *, context=None) -> AsyncIterator[StreamResponse]
async def list_tasks(self, request: ListTasksRequest, *, context=None) -> ListTasksResponse
async def get_extended_agent_card(self, request, *, context=None, signature_verifier=None) -> AgentCard
async def close(self) -> None
```

`send_message` is **always an async iterator of `StreamResponse`**:

- If `config.streaming` is False **or** `card.capabilities.streaming` is False → JSON-RPC
  `SendMessage`; yields exactly one `StreamResponse` with `task` or `message` set. With
  `return_immediately=False` (default) the server holds the call until the task is terminal or
  interrupted (`INPUT_REQUIRED`/`AUTH_REQUIRED`) — measured.
- Otherwise → `SendStreamingMessage` over SSE; yields, in order observed:
  `task` (SUBMITTED) → `status_update` (WORKING) → `artifact_update`* → `status_update`
  (COMPLETED | INPUT_REQUIRED | FAILED | CANCELED | …). The iterator **ends on a `message`
  event** or when the server closes the stream (it closes after a terminal/interrupted status).

`StreamResponse` is a oneof `payload`: `task | message | status_update | artifact_update`
(`ev.WhichOneof('payload')`).

- **GetTask:** `GetTaskRequest(id=..., history_length=?)` → `Task`.
- **CancelTask:** `CancelTaskRequest(id=..., metadata=?)` → `Task` in `TASK_STATE_CANCELED`.
  A terminal task raises `TaskNotCancelableError` (-32002). An open stream for that task then
  receives `status_update CANCELED` and ends (measured).
- **Resubscribe:** `subscribe(SubscribeToTaskRequest(id=...))` (JSON-RPC `SubscribeToTask`).
  Raises `NotImplementedError` client-side if streaming is off on either side; a terminal task
  yields `UnsupportedOperationError` (-32004, measured).
- **Reply to INPUT_REQUIRED:** send a new `Message` with the same `task_id` and `context_id`;
  the server calls `execute()` again on that task (measured, both modes).

### 1.4 Building the Message (contextId, taskId, metadata)

```python
from a2a.types import Message, Part, Role, SendMessageRequest, SendMessageConfiguration

m = Message(
    role=Role.ROLE_USER,
    message_id=str(uuid4()),
    context_id=ctx_id,  # stable per conversation ('' => server generates)
    task_id=task_id,  # only when replying to an existing task
    parts=[Part(text="...")],
)
m.metadata.update({"origin": "agent", "traceparent": tp})  # google.protobuf.Struct
req = SendMessageRequest(
    message=m, configuration=SendMessageConfiguration(accepted_output_modes=["text/plain"])
)
req.metadata.update({...})  # request-level metadata (distinct from message metadata!)
```

Two different metadata maps exist: `Message.metadata` and `SendMessageRequest.metadata`.
Server-side `RequestContext.metadata` returns the **request** one; message metadata is at
`context.message.metadata` (measured). We put `origin` / `traceparent` on the **message**
(it is persisted in task history) and read it from there.

### 1.5 Auth headers and other per-call headers

```python
# a2a/client/interceptors.py
@dataclass
class BeforeArgs: input: Any; method: str; agent_card: AgentCard;
                  context: ClientCallContext | None = None; early_return: Any | None = None
@dataclass
class AfterArgs:  result: Any; method: str; agent_card: AgentCard;
                  context: ClientCallContext | None = None; early_return: bool = False
class ClientCallInterceptor(ABC):
    async def before(self, args: BeforeArgs) -> None: ...
    async def after(self, args: AfterArgs) -> None: ...
```

`before` may replace `args.context`; the transport turns `context.service_parameters` into
request headers and `context.timeout` into `httpx.Timeout`. `after` runs for **every**
`StreamResponse` of a stream — a natural hook for trace and event counting.
`method` is one of `send_message`, `send_message_streaming`, `get_task`, `cancel_task`,
`subscribe`, … The SDK also ships `AuthInterceptor(CredentialService)` that maps the card's
`security_schemes` (bearer / oauth2 / oidc / apiKey-in-header) to headers;
`CredentialService.get_credentials(scheme_name, context) -> str | None`. We implement our own
`CredentialService` backed by env vars/callables, or a single interceptor of our own — either way
the secret only lives in the header dict, never in trace or errors. Interceptors are **not**
applied to the card fetch (it is a plain GET); card auth, if ever needed, goes via
`resolver_http_kwargs` or our own fetch.

### 1.6 Card signatures

Supported, behind the `signing` extra of the SDK (needs PyJWT):

```python
# a2a/utils/signing.py  (ImportError at import time if PyJWT is missing)
def create_signature_verifier(
    key_provider: Callable[[str | None, str | None], PyJWK | str | bytes],  # (kid, jku) -> key
    algorithms: list[str]) -> Callable[[AgentCard], None]
def create_agent_card_signer(signing_key, protected_header: ProtectedHeader,
                             header: dict | None = None) -> Callable[[AgentCard], AgentCard]
class SignatureVerificationError(Exception)          # base, NOT an A2AError
class NoSignatureError(SignatureVerificationError)
class InvalidSignaturesError(SignatureVerificationError)
```

JWS (detached payload) over the RFC 8785 canonical JSON of the card minus `signatures`; succeeds
if any signature verifies. Pass it as `signature_verifier=` to `create_from_url` /
`A2ACardResolver.get_agent_card` / `get_extended_agent_card`, or call it directly on the parsed
card (our path). Measured: valid → ok, unsigned → `NoSignatureError`, tampered →
`InvalidSignaturesError`.

Caveats: (a) `key_provider` receives the `jku` from the (untrusted) card header — fetching it
must go through `net` and the allow-list, or keys must be pinned by `kid`; (b) PyJWT is **not**
in our base deps (`a2a-sdk` core does not pull it; it only arrives transitively via some
framework extras). With `require_signature=False` by default, `policy` imports
`a2a.utils.signing` lazily and, when signatures are required but PyJWT is absent, raises
`PolicyRejected` with an install hint. Whether to add a `signing` extra is left to T3.

## 2. Server

### 2.1 AgentExecutor

```python
# a2a/server/agent_execution/agent_executor.py
class AgentExecutor(ABC):
    async def execute(self, context: RequestContext, event_queue: EventQueue) -> None: ...
    async def cancel(self, context: RequestContext, event_queue: EventQueue) -> None: ...
```

Rules that bite (measured or read in source):

- **For a new task the executor must enqueue a `Task` before any status/artifact event**, or the
  handler fails the call with `InvalidAgentResponseError` (-32006, "Agent should enqueue Task
  before TaskStatusUpdateEvent event"). `TaskUpdater` does *not* do this. Pattern:
  `if context.current_task is None: await event_queue.enqueue_event(new_task(context.task_id,
  context.context_id, TaskState.TASK_STATE_SUBMITTED, history=[context.message]))`.
- Immediate answer alternative: enqueue a single `Message` and return (no task).
- `INPUT_REQUIRED` / `AUTH_REQUIRED`: publish the status and **return**; the next message with
  that `task_id` calls `execute()` again with `context.current_task` set.
- Unhandled exceptions in `execute()` → task becomes `TASK_STATE_FAILED`.
- Cancel: the running `execute()` gets `asyncio.CancelledError`, then `cancel()` is called; it
  should publish `TASK_STATE_CANCELED`.

### 2.2 RequestContext

```python
# a2a/server/agent_execution/context.py
class RequestContext:
    def get_user_input(self, delimiter: str = '\n') -> str     # joins text parts only
    message: Message | None            # incoming message (parts, metadata, role)
    task_id: str | None                # generated if absent
    context_id: str | None             # generated if absent
    current_task: Task | None          # existing task when replying
    related_tasks: list[Task]
    configuration: SendMessageConfiguration | None
    metadata: dict[str, Any]           # SendMessageRequest.metadata (not message metadata)
    call_context: ServerCallContext    # identity

class ServerCallContext(pydantic.BaseModel):
    state: MutableMapping[str, Any]    # default builder puts 'headers' (dict) and 'auth'
    user: User                         # a2a.auth.user.User: .is_authenticated, .user_name
    tenant: str = ''
    requested_extensions: set[str]
```

Parts: `a2a.helpers.get_text_parts(parts) -> list[str]`, `get_data_parts(parts) -> list[Any]`
(JSON via `MessageToDict`), `get_raw_parts`, `get_url_parts`, `get_message_text(message)`.
**Caller identity:** `context.call_context.user.user_name` (measured: `"peer-agent"` from a
Starlette `SimpleUser`).

### 2.3 Emitting events: TaskUpdater / EventQueue

```python
# a2a/server/events/event_queue.py
Event = Message | Task | TaskStatusUpdateEvent | TaskArtifactUpdateEvent
class EventQueue(ABC):  async def enqueue_event(self, event: Event) -> None ...

# a2a/server/tasks/task_updater.py
class TaskUpdater:
    def __init__(self, event_queue: EventQueue, task_id: str, context_id: str,
                 artifact_id_generator=None, message_id_generator=None)
    async def update_status(self, state: TaskState, message: Message | None = None,
                            timestamp: str | None = None, metadata: dict | None = None)
    async def add_artifact(self, parts: list[Part], artifact_id: str | None = None,
        name: str | None = None, metadata: dict | None = None, append: bool | None = None,
        last_chunk: bool | None = None, extensions: list[str] | None = None)
    async def submit / start_work / complete / failed / reject / cancel /
              requires_input / requires_auth (self, message: Message | None = None)
    def new_agent_message(self, parts: list[Part], metadata: dict | None = None) -> Message
```

Our flow: `new_task(...)` (if new) → `start_work()` → `add_artifact([...], name="answer")` →
`complete()`; or `requires_input(updater.new_agent_message([new_text_part(question)]))`;
or `failed(...)`. After a terminal state `update_status` raises `RuntimeError`.

### 2.4 Handler, task store, routes

```python
# a2a/server/request_handlers/__init__.py: DefaultRequestHandler = DefaultRequestHandlerV2
DefaultRequestHandler(agent_executor: AgentExecutor, task_store: TaskStore | VersionedTaskStore,

# a2a/server/routes
create_agent_card_routes(agent_card: AgentCard,
    card_modifier: Callable[[AgentCard], Awaitable[AgentCard]] | None = None,
    card_url: str = '/.well-known/agent-card.json', cache_control: str | None = None) -> list[Route]
create_jsonrpc_routes(request_handler: RequestHandler, rpc_url: str,

add_a2a_routes_to_fastapi(app, *, agent_card_routes=None, jsonrpc_routes=None, rest_routes=None)
```

There is **no app class** in 1.2.3: the app is `Starlette(routes=[*create_agent_card_routes(card),
*create_jsonrpc_routes(handler, rpc_url='/a2a')], middleware=[...])`. The card route is `GET
/.well-known/agent-card.json` (with weak ETag / 304); JSON-RPC is a single `POST rpc_url`
(spec §3.4 uses `/a2a`; the card's `AgentInterface.url` must then end in `/a2a`). Requires
`a2a-sdk[http-server]` (starlette + sse-starlette) — our `server` extra.

### 2.5 Authentication

The SDK does not authenticate. `DefaultServerCallContextBuilder.build(request)` copies
`request.user` (if Starlette's `AuthenticationMiddleware` set one) into
`ServerCallContext.user` via `StarletteUser`, plus `state['headers']` and `state['auth']`.
So `create_app` adds `Middleware(AuthenticationMiddleware, backend=<our backend>,
on_error=<401 JSON>)`, where the backend wraps the user's auth callable / API-key helper and
lets `/.well-known/agent-card.json` through. Default Starlette `on_error` answers **400**
plain text (measured) — we override to 401. A custom `ServerCallContextBuilder` is the
alternative hook (subclass, `build(request) -> ServerCallContext`) if we need to add `origin`
to the call context.

### 2.6 Version negotiation

`JsonRpcDispatcher` decorates request processing with
`a2a.utils.version_validator.validate_version('1.0')`: it reads `A2A-Version` from
`state['headers']`; **missing header = `0.3`**; incompatible when the major differs →
`VersionNotSupportedError` (-32009). Measured: no header → -32009; `2.0` → -32009; `1.0` ok
(`1.x` accepted). With `enable_v0_3_compat=True` the dispatcher also accepts v0.3 method names.
We leave compat off. Nothing to build here beyond surfacing -32009 as `UnsupportedVersion`.

## 3. Models

All protocol types are protobuf messages (`a2a/types/a2a_pb2.py`, package `lf.a2a.v1`),
re-exported from `a2a.types`. Construct with keyword args; serialize with
`google.protobuf.json_format.MessageToDict(msg)` (camelCase keys) and parse with
`ParseDict(d, Type(), ignore_unknown_fields=True)`; for cards prefer
`a2a.client.card_resolver.parse_agent_card(d)` (handles v0.3 shapes). Struct/Value fields
(`metadata`, `Part.data`) take plain dicts (`m.metadata.update({...})`).

| Type | Fields (1.2.3) |
|---|---|
| `AgentCard` | `name`, `description`, `supported_interfaces: [AgentInterface]`, `provider: AgentProvider`, `version`, `documentation_url?`, `capabilities: AgentCapabilities`, `security_schemes: map<str, SecurityScheme>`, `security_requirements: [SecurityRequirement]`, `default_input_modes: [str]`, `default_output_modes: [str]`, `skills: [AgentSkill]`, `signatures: [AgentCardSignature]`, `icon_url?` |
| `AgentInterface` | `url`, `protocol_binding` (`'JSONRPC'`/`'HTTP+JSON'`/`'GRPC'`), `tenant`, `protocol_version` (`'1.0'`) |
| `AgentCapabilities` | `streaming?`, `push_notifications?`, `extensions: [AgentExtension]`, `extended_agent_card?` |
| `AgentSkill` | `id`, `name`, `description`, `tags`, `examples`, `input_modes`, `output_modes`, `security_requirements` |
| `Message` | `message_id`, `context_id`, `task_id`, `role: Role`, `parts: [Part]`, `metadata: Struct`, `extensions`, `reference_task_ids` |
| `Part` | oneof `content`: `text: str` \| `raw: bytes` \| `url: str` \| `data: google.protobuf.Value`; plus `metadata`, `filename`, `media_type` |
| `Task` | `id`, `context_id`, `status: TaskStatus`, `artifacts: [Artifact]`, `history: [Message]`, `metadata` |
| `TaskStatus` | `state: TaskState`, `message: Message`, `timestamp: Timestamp` |
| `Artifact` | `artifact_id`, `name`, `description`, `parts: [Part]`, `metadata`, `extensions` |
| `TaskStatusUpdateEvent` | `task_id`, `context_id`, `status`, `metadata` |
| `TaskArtifactUpdateEvent` | `task_id`, `context_id`, `artifact`, `append`, `last_chunk`, `metadata` |
| `SecurityScheme` | oneof: `api_key_security_scheme`, `http_auth_security_scheme`, `oauth2_security_scheme`, `open_id_connect_security_scheme`, `mtls_security_scheme` |

Enums: `Role.ROLE_USER = 1`, `Role.ROLE_AGENT = 2`; `TaskState`: `TASK_STATE_UNSPECIFIED=0`,
`SUBMITTED=1`, `WORKING=2`, `COMPLETED=3`, `FAILED=4`, `CANCELED=5`, `INPUT_REQUIRED=6`,
`REJECTED=7`, `AUTH_REQUIRED=8` (all prefixed `TASK_STATE_`; `TaskState.Name(v)` gives the
string). There is no separate "file part" type in 1.x: files are `raw` (inline bytes) or `url`
parts — our `accept_parts` maps `"file"` to both, and `"data"` to `Part.data`.

Helpers (`a2a.helpers`): `new_text_part`, `new_data_part`, `new_raw_part`, `new_url_part`,
`new_text_message`, `new_message`, `new_task`, `new_task_from_user_message`,
`new_text_artifact`, `new_data_artifact`, `get_message_text`, `get_artifact_text`,
`get_stream_response_text`, `get_text_parts`, `get_data_parts`, `get_raw_parts`, `get_url_parts`.

Wire example (`MessageToDict` of a message, measured):
`{'messageId': 'm-hi', 'role': 'ROLE_USER', 'parts': [{'text': 'hi'}], 'metadata': {...}}`.

### State mapping (our `Result`)

| `TaskState` | Our outcome |
|---|---|
| `COMPLETED` | `Result(ok)` — text parts → `answer`, data parts → `data` (after size/part policy) |
| `INPUT_REQUIRED`, `AUTH_REQUIRED` | `Result(pending)` with the question text and `task_id`/`context_id`; never auto-answered |
| `FAILED`, `REJECTED`, `CANCELED` | `TaskFailed` (state + status message text) |
| `SUBMITTED`, `WORKING` | non-final; on stream end / cap → `A2ATimeout` |
| `UNSPECIFIED` | protocol violation → `TaskFailed` |
| a bare `Message` response | `Result(ok)` from its parts |

## 4. Errors

Hierarchy: `a2a.utils.errors.A2AError(Exception)` (attrs `message: str`, `data: dict | None`).
Name clash with our `A2AError`: import the SDK one as `from a2a.utils import errors as sdk_errors`.

| Situation | Raised by the SDK client | Our mapping |
|---|---|---|
| Card fetch: HTTP error / network / bad JSON / bad shape | `AgentCardResolutionError(A2AClientError)` (`.status_code`) | `PolicyRejected` (or `BlockedDestination` if raised by `net`) |
| No JSONRPC interface in card | `ValueError('no compatible transports found.')` | `UnsupportedVersion` / `PolicyRejected` |
| JSON-RPC error with known code | the matching `a2a.utils.errors` class, `.data` = `ErrorInfo.metadata` | see below |
| -32001 `TaskNotFoundError` | | `TaskFailed` (task not found) |
| -32002 `TaskNotCancelableError` | | `TaskFailed` / no-op on `cancel()` |
| -32004 `UnsupportedOperationError` (e.g. subscribe to terminal task) | | `TaskFailed` |
| -32005 `ContentTypeNotSupportedError` | | `PolicyRejected` |
| -32006 `InvalidAgentResponseError` | | `TaskFailed` |
| -32009 `VersionNotSupportedError` | | `UnsupportedVersion` |
| -32600/-32601/-32602/-32603/-32700 | `InvalidRequestError`, `MethodNotFoundError`, `InvalidParamsError`, `InternalError`, `JSONParseError` | `TaskFailed` |
| Unknown JSON-RPC code | `A2AClientError('JSON-RPC Error {code}: {message}')` | `TaskFailed` |
| `httpx.TimeoutException` | `A2AClientTimeoutError` | `A2ATimeout` |
| HTTP 4xx/5xx on RPC, `httpx.RequestError`, JSON decode | `A2AClientError` (message includes URL/status) | `TaskFailed`, or `BlockedDestination` when the cause is ours (check `__cause__`) |
| SSE `event: error` | the mapped JSON-RPC error, else `A2AClientError` | as above |

Exceptions raised inside our custom transport propagate wrapped: `httpx.RequestError`
subclasses become `A2AClientError` with `__cause__` set; anything else propagates as-is. T2
should therefore raise `BlockedDestination` (not an `httpx` subclass) so it surfaces unchanged —
to be confirmed by T2's tests. Errors may embed the URL and server message; never credentials
(headers are not included) — but we still rebuild messages instead of passing SDK text through.

## 6. Gaps the SDK does not cover (we build them)

1. **Egress safety:** no DNS/IP checks, no pinning, no body size limit (client reads
   `response.json()` / `aiter_lines()` unbounded). → `net` transport.
2. **Version rejection on the client:** the client silently downgrades to v0.3 compat and never
   refuses a card; we check `supported_interfaces[*].protocol_version` major == 1 for the
   `JSONRPC` interface → `UnsupportedVersion`.
3. **Wall-clock timeout and event caps for streams:** `ClientCallContext.timeout` is an httpx
   per-operation timeout, so a stream emitting `WORKING` forever never times out. → wrap the
   iterator with `asyncio.timeout` / deadline + `max_events` → `A2ATimeout`.
4. **Part filtering / untrusted wrapping / Result normalization:** none in the SDK.
5. **Host allow-list, budgets, origin marking, trace (`traceparent` not propagated by the SDK;
   its OTel spans are internal only, toggled by `OTEL_INSTRUMENTATION_A2A_SDK_ENABLED`).**
6. **Server authentication:** none; plus Starlette's default auth error is HTTP 400 → our
   middleware + `on_error` 401, and `serve()` refuses to start without auth unless `insecure=True`.
7. **Server request size limit:** `JsonRpcDispatcher` does `await request.json()` with no cap →
   body-size middleware in `create_app`.
8. **Executor boilerplate:** must enqueue the initial `Task` itself (see §2.1).
9. **Lifecycle quirk:** `client.close()` closes our `httpx.AsyncClient`.
10. **Signature key fetching:** `key_provider` receives an untrusted `jku`; key retrieval must go
    through `net` / pinned keys. PyJWT not in base deps.
11. **Logging:** the card resolver logs the full card at INFO and the server dispatcher logs
    full request bodies at DEBUG (`a2a.*` loggers). Fine for cards; for bodies we document that
    DEBUG on `a2a.server` may log remote content.

## Consequences

- Protobuf stays behind our boundary; adapters and users see `Result`/`CardSpec` only.
- Upgrading within `<2` is guarded by interop tests (our client ↔ SDK server, SDK client ↔ our
  server). Watch points on upgrade: `ClientFactory` header mutation, `client.close()` semantics,
  the "Task before status" rule, and `validate_version`'s missing-header default.
